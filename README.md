Sekeping.my V23 — Kamera Ringkas & Kemas

Penambahbaikan kamera:
- Filter dipermudahkan kepada beberapa pilihan utama sahaja:
  Asli, Klasik 94, Kodak Gold, Fuji 400, Dreamy, dan B&W Klasik.
- Hasil tangkapan dan gambar dari galeri diproses menggunakan filter semasa,
  jadi filter akan kekal pada gambar yang disimpan.
- Ditambah fungsi Sembunyi / Tunjuk untuk rail filter pantas.
- Butang shutter kini diletakkan betul-betul di tengah.
- Nota kecil ditambah untuk memaklumkan bahawa filter akan kekal pada gambar.
- Fail asal tidak diubah; ini ialah versi berasingan.
